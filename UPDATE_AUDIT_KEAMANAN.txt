UPDATE AUDIT KEAMANAN SIMA

Perubahan:
1. Halaman "Log Sistem" diubah menjadi "Audit Keamanan".
2. Tabel mengikuti referensi: WAKTU | EVENT | PENGGUNA | DESKRIPSI | IP.
3. Ditambahkan pencarian pengguna, IP, dan deskripsi.
4. Ditambahkan filter event dan rentang tanggal.
5. Ditambahkan penyimpanan alamat IP pada audit log.
6. Login berhasil, login gagal, logout, dan mutasi data dicatat sebagai event audit.
7. Event CREATE/UPDATE/DELETE lama tetap tampil sebagai DATA.MUTATION.
8. Ditambahkan pagination 20 log per halaman.

Setelah update jalankan:
php artisan migrate
php artisan optimize:clear

Jika menggunakan Docker:
docker compose exec app php artisan migrate --force
docker compose exec app php artisan optimize:clear
